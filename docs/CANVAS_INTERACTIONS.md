# 无限画布交互参考

本项目的节点选择、结果浏览、来源定位和移动端布局来自公开产品观察与本地回归需求。早期内部记录中的第三方页面、会话链接和网络追踪不属于 Canvas 源码，已移除。

Canvas 的设计原则：

- 单击节点编辑输入，拖动节点只改变位置；已有结果可以继续作为参考。
- 预览支持缩略图切换、键盘操作和定位来源；关闭预览后保留原选择和视口。
- 生成任务与编辑输入分开保存；任务完成不会抢走焦点或覆盖历史结果。
- 窄屏使用底部面板，主图保持比例，主要操作位于可视区域内。

这些是 Canvas 自己的产品决策，不是对任何第三方应用内部实现的声明。验证使用本机 fixture。
