# 画布交互研究记录

Canvas 的交互设计参考了公开的无限画布产品和本项目自己的 fixture 回归。早期开发中曾保存第三方页面的网络录制；这些录制包含私有接口、会话标识和遥测信息，现已从开源目录移除。

当前设计结论：

- 画布保存、任务查询和模型目录通过平台 App Session Gateway 完成，不直接调用宿主管理接口。
- 任务提交保存原始输入和幂等键；提交响应丢失时查询原任务，不能盲目创建重复任务。
- 供应商结果未确认时保持待核验状态，不能把一次网络超时当成任务失败。
- 网格、节点、连线和预览动画尊重减少动效设置，并使用本地 fixture 验证。

实现与测试见 [架构说明](ARCHITECTURE_REVIEW.md)、[交互验证](INTERACTION_REVIEW.md) 和项目 README。
