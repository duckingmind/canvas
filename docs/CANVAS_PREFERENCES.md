# 画布偏好设置实现清单

本次整理后保留 **28 项偏好设置**，分布在交互操作、任务提示、连线设置、网格与布局、画布外观五类。「账户与保存」是第六个面板分类，提供账户与文档操作，不计入偏好设置数量。

配置的界面、类型、默认值、存储和实际使用方保持一致。未形成完整产品行为的 9 个配置入口和存储字段已删除；这不表示这些能力在技术上永远无法实现。

## 已保留并接入的设置

### 交互操作（11 项）

| 界面名称 | 配置字段 | 实际行为 |
| --- | --- | --- |
| 画布平移灵敏度 | `panSensitivity` | 控制拖动画布及滚轮平移的移动距离，范围 0.5–2.5 倍。 |
| 定位动画节点上限 | `locateAnimationLimit` | 画布节点总数超过上限时，定位和适应画布直接跳转；0 表示有节点时直接跳转，范围 0–300。 |
| 空白区域操作 | `blankAreaAction` | 决定在画布空白处右键或双击打开创建菜单，默认使用双击菜单。节点自身菜单不受影响。 |
| 滚轮默认操作 | `wheelDefaultAction` | 选择普通滚轮平移或缩放；Ctrl / ⌘ + 滚轮始终缩放，Shift + 滚轮临时平移。 |
| 参考图标签 | `referenceNaming` | 创作面板参考图显示名称或序号；不改变实际提交的参考图，也不承担提示词 `@` 语法解析。 |
| 拖拽吸附网格 | `snapToGrid` | 拖动节点时按配置的世界坐标网格间距吸附，缩放不改变吸附精度。 |
| 对齐辅助线 | `alignmentGuides` | 拖动节点或多选集合时，显示附近其他节点边缘和中心的对齐参考线；只提供视觉参考，不改变节点位置。 |
| 拖动后选中节点 | `focusOnDrag` | 开启时保留拖动节点的选中状态；关闭时在拖动完成后恢复原来的选择。单击选择不受影响。 |
| 提交后取消选中 | `clearFocusAfterSubmit` | 提交新的生成任务后清除节点选择并收起创作面板；恢复已有任务不会因该设置清除当前选择。 |
| 视频悬停预览 | `hoverVideoAutoplay` | 鼠标悬停视频时进行静音预览，移开或关闭开关后停止预览；主动操作原生播放控件后交还用户控制。 |
| 减少动效 | `reduceMotion` | 关闭画布定位、滚轮缓动及界面过渡/循环动画。系统「减少动态效果」偏好仍受到尊重。 |

主要使用方：[App.tsx](../src/App.tsx)、[geometry.ts](../src/geometry.ts)、[CreatorPanel.tsx](../src/CreatorPanel.tsx)、[alignment-guides.ts](../src/alignment-guides.ts)、[CanvasVideo.tsx](../src/CanvasVideo.tsx)、[video-hover-preview.ts](../src/video-hover-preview.ts)、[viewport-motion.ts](../src/viewport-motion.ts)、[styles.css](../src/styles.css)。

### 任务提示（2 项）

| 界面名称 | 配置字段 | 实际行为 |
| --- | --- | --- |
| 后台任务完成提示 | `notifyGeneration` | 新的生成请求或恢复查询收到完成结果时显示一次画布内提示；结果已在当前视野且选中时不重复弹出。 |
| 生成失败提示 | `notifyFailure` | 请求确认生成失败时显示一次画布内提示，不会隐藏节点中的错误和恢复操作。 |

提示使用请求身份去重。载入文档、撤销或打开提示开关不会重新提示已有结果。保存成功只更新画布顶部的持久状态，不再额外弹出重复 Toast。关闭提示只关闭瞬时提示，实际任务状态、错误详情和保存状态仍然显示。实现：[canvas-notifications.ts](../src/canvas-notifications.ts) 与 App 中的实际操作完成回调。

### 连线设置（6 项）

| 界面名称 | 配置字段 | 实际行为 |
| --- | --- | --- |
| 连线样式 | `connectionStyle` | 已有连线与拖拽中的预览线实时切换曲线、直线、正交线。 |
| 连线颜色 | `connectionColor` | 普通连线使用柔和色、画布强调色或源节点颜色；无节点颜色时回退柔和色。悬停和选中仍保留清晰反馈。 |
| 显示节点连线 | `showEdges` | 控制已有连线的显示，不删除连接关系。 |
| 显示连线箭头 | `showConnectionArrows` | 控制已有连线的方向箭头，包括选中或相关连线。 |
| 端口磁性吸附 | `magneticSnap` | 控制附近端口的吸附与接近提示；关闭后悬停/选中节点仍显示可操作的固定端口，仍可直接连接。 |
| 显示连线预览 | `connectionPreview` | 控制拖拽连线时的临时预览线，不影响完成连接。 |

主要使用方：App 的连线命中、绘制逻辑，以及 geometry 的路径生成。CSS 使用 `--edge-stroke` 和 `canvas-no-magnet`，箭头显示由设置控制，不再由选中样式强制开启。

### 网格与布局（7 项）

| 界面名称 | 配置字段 | 实际行为 |
| --- | --- | --- |
| 显示网格 | `gridVisible` | 实时显示或隐藏背景网格；不关闭节点吸附。 |
| 网格样式 | `gridStyle` | 实时切换点阵或线条。原有「关闭」选项已合并到显示开关。 |
| 网格间距 | `gridSize` | 选择 10、20、40 的世界坐标间距，同时供显示和拖拽吸附使用。缩小时显示网格自动稀疏化。 |
| 显示小地图 | `showMinimap` | 与底部小地图按钮、地图关闭按钮共享同一状态。 |
| 显示节点状态标签 | `showNodeStatus` | 控制节点标题栏状态文字；不隐藏生成进度卡片、错误和重试操作。 |
| 节点内容密度 | `nodeDensity` | 紧凑模式减少节点标题、工具栏、文本和卡片的内部间距，不改写节点保存的宽高、位置或连接。 |
| 默认整理方式 | `autoLayout` | 决定快捷整理画布/选中节点时使用流程或网格排列。切换设置本身不会移动节点；用户在整理菜单显式选定的其他布局仍优先。 |

主要使用方：App 的网格、拖拽、小地图和整理逻辑；紧凑样式通过根节点的 `canvas-density-compact` 生效。

## 已清理的设置（9 项）

这些字段已从 TypeScript 类型、默认值、设置界面和存储规范化输出中移除。没有将它们留作「可切换但无效果」的开关。

| 原设置 | 原字段 | 当前移除的原因 |
| --- | --- | --- |
| 图/视延迟提交 | `delayedSubmit` | 没有定义延迟时长、取消窗口、刷新恢复和提交时点；任务系统已有明确的提交与持久化流程，不能只增加一个延迟开关。 |
| 触摸点吸附范围 | `touchSnapRange` | 原名称与单位未对应明确的触控交互行为。当前保留实际连线端口的磁性吸附开关，不暴露未定义的第二套范围参数。 |
| 极简模式缩放 | `minimalZoom` | 没有定义哪些信息在哪些缩放级别折叠。保留当前实际缩放范围与网格稀疏化，不提供未定义模式。 |
| 联动预览画布素材 | `linkedPreview` | 现有素材预览没有独立、可切换的跨面板联动协议；节点和素材的实际预览操作继续可用。 |
| 系统通知 | `browserNotification` | 尚无权限申请、宿主/浏览器兼容、后台生命周期和通知回跳的完整产品流程；本次只提供真实的画布内通知。 |
| 提示音 | `notificationSound` | 尚无经过设计的声音资源、解锁播放与通知去重方案；保留可控制的视觉提示。 |
| 折叠已完成结果 | `collapseCompletedResults` | 自动折叠将影响可编辑内容和节点结构，尚未定义恢复入口、多结果与保存语义。 |
| 主题模式（深色/浅色/跟随系统） | `theme` | 现有浅色只覆盖少量样式，跟随系统未形成完整主题；移除不完整模式，保留已适配的深色界面、底色和强调色。 |
| 简化配色 | `simplifiedPalette` | 之前只改变网格透明度，与名称不符；已有背景、强调色和减少动效能提供明确可见的调整。 |

若未来重新开放这些设置，应先定义产品行为、权限/恢复边界和验证方式，再同时接入界面与实际使用逻辑。

## 保存、迁移与恢复默认

- 偏好保存在当前浏览器、当前站点源的 localStorage，键为 `codex.canvas.preferences.v1`，在同一浏览器该站点的画布间共用。它们不是画布文档内容，也不做账户云同步。
- 修改后即时应用，并保存到本地；刷新后重新载入。浏览器禁止或无法写入 localStorage 时，本次打开仍可使用设置，但不保证下次载入保留。
- 载入时按白名单规范化，丢弃已删除字段、未知字段和无效枚举值；数值裁剪到界面允许范围。保存时再次规范化，避免把旧字段写回。
- 历史 `gridStyle: "none"` 转换为 `gridVisible: false` 与 `gridStyle: "dots"`，保留原来隐藏网格的视觉结果，之后可通过显示开关正常开启。
- 「恢复默认」重置全部 28 项偏好并保存；不会删除或改写节点、连线、任务或画布文件。
- 设置面板保留非模态浮窗交互：外观和显示设置即时反馈；整理方式等面向下一次操作的设置在文案中说明生效时点。

配置读取、迁移、范围、保存重载和恢复默认由 [canvas-preferences.test.ts](../tests/canvas-preferences.test.ts) 覆盖。通知去重、路径、滚轮、对齐线和视频预览由对应功能测试覆盖；这些测试不替代真实浏览器中的视觉和触控体验验收。
