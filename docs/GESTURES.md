# 画布手势梳理

## 原有冲突

- 所有滚轮事件都缩放，忽略横向滚动和滚动单位，触控板双指滑动无法平移。
- 鼠标、触屏指针共用拖动状态，没有手势所属指针及双指接管逻辑；第二根手指可能覆盖第一次拖动。
- 节点拖动达到阈值后才捕获指针，按下后离开画布可能漏掉抬起事件；丢失捕获也没有统一清理。
- 中键、空格和抓手经过端口或连线时，会被各自的点击逻辑截获。
- 取消拖动会同时关闭编辑面板；普通点击已经多选的节点不能回到单选。
- 连接端口和尺寸手柄的热区随画布缩放，缩小时难以命中。

## 统一后的操作

| 区域／输入 | 行为 |
| --- | --- |
| 点击创作节点 | 松开后选中并打开编辑；已有结果仍可继续生成。 |
| 双击文本／图片 | 编辑文本／预览图片；拖动及抓手操作不会触发双击操作。 |
| 左键拖节点 | 超过 5 个屏幕像素后移动；触屏阈值为 8 像素。拖动整组多选节点，单击其中一个回到单选。 |
| 左键拖空白 | 框选；Shift 保留已有选中，Esc 恢复框选前的选择。 |
| 滚轮／触控板双指滑动 | 双轴平移；Shift＋纵向滚轮横向平移。 |
| Ctrl／⌘＋滚轮、触控板捏合 | 以指针所在位置缩放，限制在 5%～300%。 |
| Ctrl／⌘＋加号／减号 | 以画布中心放大／缩小，支持连续按键，输入及编辑区域不触发。 |
| 底部比例按钮 | 打开带箭头的缩放浮窗；滑杆实时显示比例，提供 50%／100%、适合屏幕、放大／缩小，有选中节点时提供定位。操作后保持展开，点击画布空白处或 Esc 关闭。 |
| 中键、Space＋拖动、抓手 | 平移画布，优先于节点、连线、连接端口和尺寸手柄。节点工具按钮仍可正常点击。 |
| 触屏单指 | 空白处拖动平移；点空白取消选择，点节点编辑，拖节点移动。 |
| 触屏双指 | 接管为平移与缩放，撤回尚未提交的节点移动或尺寸调整，恢复接管前的选择。抬起一指后可继续单指平移。 |
| 输出端口 | 拖至目标建立连接；点击后再选目标；键盘激活也可进入连接模式。 |
| Esc、系统取消、失去捕获／窗口焦点 | 清理手势；节点移动与尺寸调整撤回，保留期间更新的内容和任务结果。Esc 优先取消手势，编辑面板仍可继续使用。 |
| 编辑区与原生控件 | 编辑面板独立处理文字、滚动和快捷键；原生文本控件不被画布滚轮接管。 |

每个单指操作只接受发起指针的移动与抬起事件。拖动、框选、连线及双指操作期间暂停滚轮导航，避免操作中途改变坐标基准。连接端口和尺寸手柄保持固定屏幕尺寸；触屏热区至少 44 像素，视觉尺寸保持紧凑。

拖动时暂时隐藏编辑面板，结束或取消后恢复，保留草稿。节点位置更新使用按 ID 索引的起始坐标，避免每次移动反复扫描节点；按下节点时复用不可变文档快照，避免深拷贝整张包含图片的画布。

## 验证方式

视口运动由 `src/viewport-motion.ts` 统一调度：指针拖拽与双指操作同步提交，保持一比一跟手；滚轮平移／缩放只合并下一次绘制前的输入，不再叠加额外尾部缓动，触控板的系统惯性由浏览器连续 wheel 事件自然表达；适应画布、节点定位、缩放菜单与小地图使用 220ms 过渡。新的指针操作、Esc、失焦会在当前显示位置接管，自动定位动画仍按浏览器绘制帧推进。节点、连线、网格、磁吸命中及编辑框共用同一视口，不对各层分别添加 CSS 位移动画。减少动态效果偏好下，一帧完成更新；视口停止后才启动自动保存。

- `tests/gestures.test.ts`：双轴平移、滚轮单位、指针锚点、缩放上下限、双指中点及退化输入。
- `tests/viewport-motion.test.ts`：合帧、增量累计、中断、缩放锚点、时间边界及减少动态效果。
- `tests/viewport-motion-e2e.mjs`：真实浏览器中的中间帧、最终位置、拖拽接管及编辑框跟随。
- `tests/gestures-e2e.mjs`：本机模拟平台上的真实浏览器鼠标、键盘和触屏事件，覆盖点击抖动、双击、拖动与撤销、Esc、框选、滚轮、端口优先级、画布外抬起、连线和双指接管。
- 创作及参数端到端回归继续验证编辑输入和生成流程。

端到端脚本使用隔离浏览器和本机测试数据，不调用实际模型。

2026-09-11 验证结果：105 项单元测试、类型检查和生产构建通过。Playwright Chromium 上通过 13 组手势、8 组创作与 6 组参数回归，页面运行错误为 0。触屏通过浏览器输入模拟验证双指接管、抬指衔接和取消，不代表已在所有实体触屏设备上验证。检查了 390 × 844 手机截图，以及参数面板的桌面、手机和短横屏布局。测试服务和隔离浏览器均已关闭。
