# 状态与失败恢复

先读取主应用提供的应用状态、阻塞原因和下一步动作。错误返回若含 `reason`、`retryable` 和 `nextAction`，优先据此选择查询或用户操作；`retryable: false` 表示不应盲目重放当前请求，不一定表示永远无法执行目标。目录存在表示能力已安装，不表示账号、文档或模型已经就绪。用户正在编辑、登录或切换画布时应等待相应状态完成。

| 情况 | 后续动作 |
| --- | --- |
| 等待登录 | 请用户在 Canvas 完成登录，再查状态；不尝试代填凭据。 |
| 应用未运行或文档加载中 | 让主应用启动并等待就绪；需要画布时先列出、新建或打开。 |
| `CANVAS_REVISION_CONFLICT` | 重读 `read_state`，比较用户变化后重新判断操作；若仍需修改，使用新的 revision 和新的幂等键。 |
| `CANVAS_DOCUMENT_CHANGED` / `CANVAS_WORKSPACE_CONFLICT` | 重读 `list_documents` 确认当前画布；避免把旧目标操作应用到新画布。 |
| `CANVAS_BUSY` / `CANVAS_TASK_RUNNING` | 等待画布写入或任务观察完成，重新读取状态；正在生成的节点不能更新、改类型或连接，但可以直接调用 `delete_nodes` 丢弃，编辑器会停止本地观察并忽略迟到结果。 |
| `CANVAS_MODEL_UNAVAILABLE` | 重读 `list_models` 并检查提示词媒体类型、参考输入兼容性；不静默换成未被用户接受的模型。 |
| `AGENT_IDEMPOTENCY_CONFLICT` | 同一键曾对应不同参数。找回原请求用于重试；确有新操作时生成新键。 |
| 超时、断开连接、`AGENT_OUTCOME_UNKNOWN` | 先读取画布和 `read_tasks` 核对实际结果；不要换键重复生成。必要时在应用内确认并重新打开会话，不能以重连作为重复提交依据。 |
| 任务 `failed` | 读取错误摘要并判断是否需要修正。再次生成是可能再次计费的新操作，必须符合用户当前意图。 |
| 任务 `paused: true` | 这表示本地查询暂停，不代表服务端取消。`resume_generation` 仅恢复原任务的观察；如用户要求取消，可对状态已确认、未决且已有 taskId 的视频、音乐或音色任务调用 `cancel_generation`，再用 `read_tasks` 等待平台确认。 |
| 音乐或音色提交未取得 `taskId` | 先用 `read_tasks` 核对 `submissionId`，必要时调用 `resume_generation` 恢复原冻结提交；复用原生成提交标识，不能使用新键另建同一任务。 |
| `CANVAS_MODEL_PARAMETER_UNSUPPORTED` | 重读 `list_models` 并按当前参数范围重新判断设置。歌词优化须明确支持；模型没有公布时长时不传时长。修正参数前不要提交生成。 |

已成功完成的写入在同一应用版本内复用原请求和幂等键会返回已记录结果。输出 `replayed` 不表示又执行了一次。活动区达到 64 MiB 或 50,000 条时，较早的终态记录会滚动到归档区；归档记录 7 天没有写入后自动清理，之后复用该键可能重新执行。若明确返回执行前拒绝，可修正原因后发起新操作；对于已经开始但结果不明的写入，先核对实际状态。结果未知记录不会归档或自动过期清理。

升级、切换版本或回滚后刷新目录并重新读取指南和画布状态。revision 仅用于当前运行时，幂等记录按应用版本隔离；不要跨版本重放旧写入。版本变化不能作为再次生成同一付费任务的理由。
